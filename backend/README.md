# Backend

Esta carpeta estará destinada al desarrollo del backend de BookNest.

La aplicación utilizará Python y FastAPI para implementar la API REST, la lógica de negocio y la comunicación con la capa de persistencia mediante SQLAlchemy.

En la etapa actual del proyecto todavía no se incluye código de implementación. La estructura se encuentra creada como parte de la definición inicial de la arquitectura del sistema.
